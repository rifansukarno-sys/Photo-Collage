# Photo Collage 25

Web app untuk membuat kolase hingga 25 foto langsung dari perangkat.

## Fitur
- Maksimal 25 foto
- JPG/JPEG, PNG, WebP, GIF, HEIC/HEIF, dan format gambar umum
- HEIC/HEIF diproses di browser
- Drag & drop file
- Susun ulang foto dengan drag & drop thumbnail
- Layout otomatis, square, wide, tall, grid 2/3/4 kolom
- Atur jarak dan sudut foto
- Mode Fit atau Fill
- Pilihan background
- Download PNG atau JPG
- Foto tidak diunggah ke server

## Menjalankan
Buka `index.html` di browser modern.

Untuk online, aktifkan GitHub Pages dari repository `Photo-Collage`, branch `main`, folder `/root`.
